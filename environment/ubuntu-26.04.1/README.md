# Primary Ubuntu Environment

This directory records the primary native Ubuntu environment used for Phase 0 and Phase 1.

- `environment-manifest.md` preserves the original collection record.
- `openssl-inventory.txt` records capabilities of the pinned native OpenSSL 3.5.9 build.

The initial evidence was collected in a non-Git working directory. After this repository is pulled into the Ubuntu workspace, update the repository-registration section in `environment-manifest.md` with the repository URL, branch, and the Git commit used for reproducibility. Preserve the original collection details rather than replacing them.
